# Proyecto de Mecatrónica - Tareas 1.5 y 1.6

Repositorio para la gestión de nodos en ROS 2 y el plan de datos de descarga de batería.

## Contenido del Repositorio
- `src/bateria_sim/`: Paquete de ROS 2 que incluye el nodo supervisor (`nodo_supervisor.py`).
- `generador_datos.py`: Script en Python para simular y generar el dataset de 200 misiones.
- `verificar_dataset.py`: Script de validación para comprobar la integridad del dataset.
- `dataset_misiones_bateria.csv`: Dataset consolidado con las 244,964 filas y las variables de operación.
